Welcome to my Code Scracthbook — a growing collection of small coding exercises, snippets, and tutorial experiments.
A mix of algorithms, language features, and tiny projects — all written while learning, exploring, and having fun.

# Overview:
This repository is my coding sandbox — a place where I try out new ideas, solve small programming puzzles, and follow along with tutorials.
It’s not a polished library, but a learning archive of hands-on examples that show how concepts actually work in code.

Each file or subfolder represents a different experiment — from algorithms to GUIs, from concurrency to web apps.

| Folder / File | Description |
| :--- | :--- |
| **algorithms/** | Classic algorithms (e.g., sorting, searching) implementations. |
| **gui/** | Small **GUI** (Graphical User Interface) event handling and simple application examples. |
| **headFirst/** | Code from the "Head First Python" book. |
| **impracPy/** | Practice scripts and experiments from a personal project. |
| **intermediate/** | Advanced Python topics (e.g., decorators, context managers). |
| **leetcode/** | Algorithmic challenges solved from LeetCode. |
| **testing/** | Unit test examples using frameworks like `unittest` or `pytest`. |
| Misc. `.py` files | Individual programming challenges and single-script solutions. |
| `requirements.txt` | Dependencies required to run the projects. |


###  Key Topics and Examples Covered

* **🔢 Algorithms:** Insertion sort, recursion, quicksort.
* **🧵 Concurrency:** Threading, multiprocessing.
* **🧰 Core Python:** Dictionaries, sets, tuples, list/dictionary/set comprehensions.
* **🧠 Logic Problems:** Palindrome checks, mean vs mode calculations, string counting.
* **🧪 Testing:** Unit tests with custom messages and outcomes (e.g., using `unittest` or `pytest`).
* **🌐 Web & DB:** Mini Flask-style web application (adapted from *Head First Python*).
* **🎨 GUI:** Handling mouse and button events (e.g., using `tkinter`).
* **🕹️ Playful Scripts:** Pig Latin translator, pseudonym generator, silly casing scripts.

“Tiny experiments build deep understanding.”

This repo isn’t about production-ready code — it’s about learning by doing.
Each file captures a concept, an idea, or a curiosity I wanted to explore.
Over time, it’s become a sort of interactive notebook for programming.
